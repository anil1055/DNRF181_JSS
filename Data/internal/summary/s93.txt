After careful analysis of the given research paper "Using Web Objects for Development Effort Estimation of Web Applications," the following key points can be extracted:

1.  **Research Background**: 
    The increasing adoption of Web applications highlights the need for suitable measures to size and manage them effectively. Traditional software size measurements, such as Function Point Analysis (FPA), often struggle to accurately reflect the unique characteristics of Web applications. To address this gap, Sergio Di Martino et al.'s study focuses on investigating the efficacy of Web Objects as a size metric for estimating the development effort of Web applications.

2.  **Methodology**:
    The researchers conduct a comprehensive study involving 25 Web applications developed by an Italian software company between 2003 and 2008. Their investigation utilizes multiple effort estimation techniques, including Ordinary Least Squares Regression (OLSR), Web-COBRA, and Case-Based Reasoning (CBR), along with the Web Objects size measure.

3.  **Key Findings**:
   •   The results show that Web Objects perform well when combined with OLSR, yielding higher quality predictions relative to traditional Function Points (FP).
   •   When paired with Web-COBRA, Web Objects display performance equivalent to those observed with OLSR; however, the former yields marginally better outcomes.
   •   Although CBR performs adequately when combining with Web Objects, the estimates produced do not surpass those generated by either OLSR or Web-COBRA.
   •   By examining the comparative outcome against utilizing just the mean or median effort of historical projects, the investigators demonstrate that employing sophisticated computation of software size, like Web Objects, offers enhanced predictive capabilities.

4.  **Comparison with Prior Research**
    The current research confirms findings from earlier investigations led by Ruhe et al., indicating the reliability and applicability of Web Objects in evaluating Web application development effort. Additionally, it validates the adaptability and versatility of Web Objects across various platforms and project sizes, demonstrating their potential utility in diverse development contexts.

5.  **Conclusion**
    Based upon their thorough evaluation, the researchers' primary contributions to existing knowledge comprise:
       •   Confirmatory evidence for the viability of the Web Objects measure in predicting Web application development effort, especially when coupled with established algorithms.
       •   Demonstration that the Web Objects method generates more precise predictions than traditional Function Point Analysis (FPA) when utilized alongside advanced estimation methodologies.
       •   Observations suggesting similarities in predictive efficiency amongst distinct analytical frameworks – OLSR, CBR, and Web-COBRA – when integrated with the Web Objects size metric.



Predictors Used for Estimating Web Application Efforts in the Paper:
1.  **Ordinary Least Squares Regression (OLSR)**: Utilizes a statistical model fitting to explore correlations between predictor(s) and response variable. It is particularly effective in forecasting continuous responses.
2.  **Case-Based Reasoning (CBR)**: Leverages stored examples to reason and guide decision-making processes by identifying analogous scenarios and adapting solutions thereto.
3.  **Web-COBRA (Component-Based Risk Assessment)**: Combines artificial intelligence techniques with conceptual modeling principles to incorporate expertise-driven insights during cost estimation processes.

These predictors serve as essential tools for gauging the feasibility and projected costs associated with developing complex web applications, enabling stakeholders to make informed choices throughout their planning phases.
