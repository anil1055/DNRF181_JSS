**Keywords:** Web based application software maintenance, Factor analysis, Structural equation
modeling: SEM, Bayesian analysis.

**Abstract.** The objectives of this research were to find out the Structural equation modeling
coefficient and other parameter estimation under unknown prior distribution and compare this new
model’s coefficient accuracy with the former model on “Web based application maintenance cost
estimation multi group modeling” [16]. This new coefficient and parameter were estimated with
Bayesian analysis instead of Maximum likelihood estimation (ML). The input model used in
Bayesian analysis was started from the ML-model result [16]. The new values were replaced into the
former model then MMRE was detected from 30 (testing) completed software maintenance projects
while 192 projects were used for SEM model training. The result of cross validation was about
44.08% for Bayesian analysis refined SEM model while the ML-SEM model was 47.58%.

**Introduction**

Software maintenance is effort consumption activity and may cause critical event if it cannot be
delivered to user in a suitable cost. If we can precisely estimate amount of software maintenance cost
then project planning of software maintenance could be easily defined.

The web based application software maintenance cost estimation model [16] was especially
designed for the public and private sector of Thailand web based application during 2006-2009.
Factor analysis technique and Structural equation modeling were used to find out factors and factors
relationships respectively. Indeed, these small project’s dataset [16], only 170 cases training, might
cause inaccurate estimation so that Bayesian analysis technique was chosen to refine the estimation of
parameter and coefficient results.

**Summary**

**Conclusion.**

  - Maintenance cost estimation in Eq. 5 could be used to predict software maintenance cost with
accuracy percentage 52.42%.

  - Maintenance cost estimation in Eq. 9, refined coefficient with Bayesian estimation, could
predict software maintenance cost with more accuracy percentage 55.92%.
**Suggestion for further research.** This model was small dataset then Bayesian analysis gave more
accuracy estimation cause of not require Uniform distribution assumption but if dataset increase cases
Bayesian analysis should closely to the ML estimation. In this situation, MT_Attribute and
App_Attribute were interacted together which might cause non linear effect so that Partial least
square method could be considered using to reduce this effect for increasing model prediction

accuracy.
