## **Web Based Application Maintenance Cost Estimation Modeling ** **using Bayesian SEM ** Somchai Prakancharoen

Department of Computer and Information Science Faculty of Applied Science

King Mongkut’s University of Technology North Bangkok, Thailand

spk@kmutnb.ac.th

**Keywords:** Web based application software maintenance, Factor analysis, Structural equation
modeling: SEM, Bayesian analysis.

**Abstract.** The objectives of this research were to find out the Structural equation modeling
coefficient and other parameter estimation under unknown prior distribution and compare this new
model’s coefficient accuracy with the former model on “Web based application maintenance cost
estimation multi group modeling” [16]. This new coefficient and parameter were estimated with
Bayesian analysis instead of Maximum likelihood estimation (ML). The input model used in
Bayesian analysis was started from the ML-model result [16]. The new values were replaced into the
former model then MMRE was detected from 30 (testing) completed software maintenance projects
while 192 projects were used for SEM model training. The result of cross validation was about
44.08% for Bayesian analysis refined SEM model while the ML-SEM model was 47.58%.

**Introduction**

Software maintenance is effort consumption activity and may cause critical event if it cannot be
delivered to user in a suitable cost. If we can precisely estimate amount of software maintenance cost
then project planning of software maintenance could be easily defined.

The web based application software maintenance cost estimation model [16] was especially
designed for the public and private sector of Thailand web based application during 2006-2009.
Factor analysis technique and Structural equation modeling were used to find out factors and factors
relationships respectively. Indeed, these small project’s dataset [16], only 170 cases training, might
cause inaccurate estimation so that Bayesian analysis technique was chosen to refine the estimation of
parameter and coefficient results.

**Literature References**

**Factor analysis.** [1] Factor analysis is technique of reducing some unimportance indicators and
grouping some related indicators to be new latent variable (factor or component). There are many
method used to compose indicators to new component such as Principle component analysis: PCA,
Maximum likelihood estimation: ML.

**Structural Equation Modeling: SEM.** [2] Structural equation modeling is a method of
confirmatory factor analysis. It can analyze whether a user’s purposed model of factor relation is good
or not. Estimation method of model calculation are Maximum Likelihood Estimation: ML,
Generalized Least Squares: GLS, Asymptotically distribution free: ADF, Unweighted least square
:ULS …etc. Result model of SEM must be checked with Goodness of fit by some statistics such as
Chi-square (χ [2] ) (ought to non significance), Goodness of Fit Index: GFI (exceed > 0.9), Adjusted
Goodness of Fit Index: AGFI (exceed > 0.9), Root Mean Square Error of Approximation: RMSEA
(lower than <= 0.06) and Hoelter’s N (ought to exceed 75).

**Software sizing.** Donald J.Reifer [11] present that “Web Objects”, source code sizing method, has
a similar concept to “Function Point”. “Web object” defined the web based software sizing with more
reasonable size estimation to web based application than Function point. The attribute of web object

**Bayesian analysis** . [17] Bayesian analysis was the technique to estimation of those parameters
from a given samples. Maximum likelihood in SEM assume that probability distribution of Uniform
distribution (prior) while Bayesian analysis try out the probability distribution from empirical
environment and combined it with Bayesian’s theorem to gain posterior distribution. The unknown
parameters should be estimated from this distribution without former assumption about distribution.

**Data collection.** Indicators from Table 1. were designed to be a form fill-in questionnaire. This
questionnaires were then submitted to target software department. Twenty two completed software
maintenance projects were additional collected (2009) while the amount of cases in [16] were two
hundred cases (2006-2008). In conclude, two hundred and twenty two completed software
maintenance projects were the new total amount of cases. Data from questionnaire was prepared and
cleaning before statistical processing. Some Indicator (Such as M_Cost, Web_Object) have more
skew ness than criterion (not exceed +/- 1) thus Log10 transformation for both indicator (represent
with L_M_Cost, L_Web_Object) would reduce their skewness to become a normal distribution. All
variables were transformed to standardized value, prefixed with alphabet “z”, for preventing sizing
domination of each indicator.

**Summary**

**Conclusion.**

  - Maintenance cost estimation in Eq. 5 could be used to predict software maintenance cost with
accuracy percentage 52.42%.

  - Maintenance cost estimation in Eq. 9, refined coefficient with Bayesian estimation, could
predict software maintenance cost with more accuracy percentage 55.92%.
**Suggestion for further research.** This model was small dataset then Bayesian analysis gave more
accuracy estimation cause of not require Uniform distribution assumption but if dataset increase cases
Bayesian analysis should closely to the ML estimation. In this situation, MT_Attribute and
App_Attribute were interacted together which might cause non linear effect so that Partial least
square method could be considered using to reduce this effect for increasing model prediction

accuracy.
